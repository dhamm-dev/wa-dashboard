# Private development preview

Set `DHEXBOT_PRIVATE_PREVIEW=1` in the production service's protected environment configuration before starting the process. Keep `DHEXBOT_PUBLIC_SIGNUP` unset or `0`; preview also overrides a value of `1`. Only service administrators should be able to change the environment or restart the service. This repository does not contain the production service configuration. The preview setting is captured at process startup and cannot be changed through an API request.

Startup retains previously journaled `DATA_DIR/media-temp` directories and their journal rows, creates a new private directory, and leaves incomplete `uploads-v2` files and their `upload_files` rows in place. Revocation inventory still runs and can stop startup if it is invalid. Customer revocation requests return 503; customer cleanup is unavailable. WhatsApp session repair is unavailable in preview. Ordinary auth-key removals are represented by JSON null instead of unlinking the file. Scheduling, existing account access, Google login, and logs retain their existing behavior.

Preview guards the recovery and customer cleanup paths described above; it does not intercept filesystem operations globally or provide an operating-system deletion barrier. Baileys can remove temporary files that it creates during normal media processing, and other libraries, SQLite, child processes, and external processes can modify or delete files. Files can also be overwritten, including session key files. The current SQLite DATA_DIR lock has a documented POSIX same-process file-descriptor-close vulnerability and does not prove exclusive access. Do not enable automatic recovery or customer cleanup based on that lock; a safe lock and cleanup mechanism still need proof.

Retained media and uploads may contain private customer content. They consume disk space across restarts and can expose sensitive data to anyone with filesystem or backup access. Restrict access and monitor capacity. Retention is not evidence of deletion, secure erasure, or completed customer cleanup. No customer deletion or renewed approval has been completed. Public signup must remain disabled until customer deletion is implemented and approved.
